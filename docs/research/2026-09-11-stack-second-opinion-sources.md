# Источники по границам: приложение к «Технологии Rated по границам ADR: второе мнение»

Дата: 2026-09-11. Одна строка на находку исследования. Колонки: id; технология; пункт брифа; вердикт исследователя; вид источника; адрес первоисточника; версия или дата; инструмент; линза ADR (если проверялась). Вердикт «не установлено» — тоже результат. Полные формулировки находок — в рабочих JSON исследования; здесь только то, что нужно, чтобы проверить строку основного документа.

Обозначения линзы ADR: «привязка верна» — проверяющий подтвердил, что утверждение относится к названному обязательству и вердикт из него следует; «опровергнуто: …» — исправленный вердикт, учтённый в основном документе.
